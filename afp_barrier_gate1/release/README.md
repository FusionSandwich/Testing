# AFP R5 corrected theorem release

Terminal classification: `AFP_PURE_THEOREM_INTERNAL_RELEASE_CANDIDATE_MAJOR_REVISION_CLOSED`

This directory is the controlled release surface for Prompt 03. It centers the
pure theorem, separates the numerical/design manuscript, and archives P2F as
an inconclusive diagnostic outside both papers. It does not claim external
specialist review, journal acceptance, DOI preservation, source-data
validation, or a physical HTS result.

## Release architecture

1. Pure theorem paper: `../../docs/publication_program/p1f_manuscript/FLAGSHIP_MANUSCRIPT.md`
   (built PDF: `../../output/pdf/FLAGSHIP_MANUSCRIPT.pdf`).
2. Numerical/design paper: `NUMERICAL_DESIGN_PAPER.md`. It includes P2A--P2D
   and the negative P2E outcome, but excludes P2F as a paper result.
3. P2F archive and redesign gate: `P2F_INCONCLUSIVE_ARCHIVE.md`.

## Audit controls

- `SOURCE_OF_TRUTH_MAP.md`: exact ancestry and branch dispositions.
- `PURE_THEOREM_RELEASE.md`: controlling theorem statement and scope.
- `CLAIM_EVIDENCE_MATRIX.md`: claim-by-claim classification.
- `LEAN_CLAIM_AUDIT.md`: exact finite formalization boundary.
- `LEAN_DECLARATION_INDEX.json`: all 512 public theorem/lemma declarations.
- `LEAN_RELEASE_AUDIT.log`: their `#check` signatures and `#print axioms`
  output.
- `COUNTEREXAMPLE_LEDGER.md`: falsified and rejected routes preserved.
- `PRIOR_ART_AND_NOVELTY.md`: primary-source comparison and novelty boundary.
- `REPRODUCIBILITY.md`: clean validation commands and environment boundary.
- `REVIEWER_BUNDLE.md`: hostile-audit correction guide.
- `FINAL_REPORT.md`: terminal report and unresolved external gates.

Generated byte manifests are deterministic and exclude the manifest file
itself. A passing build or test validates only the named finite artifact; it
does not promote an ordinary proof, numerical pattern, or physical assumption
to Lean-checked theorem status.
