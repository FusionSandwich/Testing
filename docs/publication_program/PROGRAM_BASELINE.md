## 4. Exact normalization conventions

### 4.1 State weights and weighted inner product

The state set is finite. Vertex weights satisfy `w_i>0`. No theorem silently assumes `sum_i w_i=1`.

```text
<f,g>_w = sum_i w_i f_i g_i.
```

A probability normalization may be introduced explicitly as `w_i/sum_k w_k`; it is not built into the generator definition. For the near-rigidity Markov normalization, the relevant measure is instead

```text
mu_i = w_i r_i,
pi_i = mu_i / sum_k mu_k.
```

### 4.2 Shared conductances and jump rates

```text
gamma_ij = gamma_ji >= 0,
a_ij = gamma_ij / w_i,
w_i a_ij = w_j a_ji = gamma_ij.
```

Strict positivity is asserted only on active edges when required. Permitted zero-conductance edges are inactive.

### 4.3 Generator sign and diagonal

```text
(Lf)_i = sum_{j != i} a_ij (f_j-f_i),
r_i = sum_{j != i} a_ij,
L_ii = -r_i.
```

Thus `L` is negative semidefinite in the reversible weighted inner product convention. Eigenmaps are written

```text
L Phi = -lambda Phi.
```

For `Phi_i in S^(d-1)`, the coordinate eigenvalue used by the sampled degree-two package is `lambda=d-1`. On `S^2`, `L Omega=-2 Omega`. The degree-two spherical target is `-2d`, hence `-6` on `S^2`.

### 4.4 Carré du champ

The conventional bilinear form is

```text
Gamma(f,g)_i =
    (1/2) sum_j a_ij (f_j-f_i)(g_j-g_i).
```

The Lean quantity `jumpCrossVariation` is `2 Gamma`. The older square-valued Lean definition `carreDuChamp` is `sum_j a_ij(f_j-f_i)^2`, also equal to `2 Gamma(f,f)`. Documents must state which convention is being used.

### 4.5 Quadratic sampling and residuals

For `A in Sym_0(d)`,

```text
(S_X A)_i = Phi_i^T A Phi_i,
K_X = ker S_X,
C_i = sum_j a_ij (Phi_j-Phi_i)(Phi_j-Phi_i)^T,
M_i = P_0(C_i+2 Phi_i Phi_i^T),
(R_X A)_i = <A,M_i>_F.
```

The Frobenius pairing is `<A,B>_F=tr(A^T B)`. The accepted structural identity is

```text
R_X = (L+2d I) S_X.
```

Therefore

```text
E_sample =
    S_X(E_form)
    = im(S_X) intersect ker(L+2d I),
```

and not merely the algebraic form kernel. An algebraically nonzero `A` may lie in `K_X` and define the zero sampled function.

### 4.6 Spherical rate–defect quantities

On `S^2`,

```text
ell_ij = 1-Omega_i dot Omega_j,
epsilon_i = sum_j a_ij ell_ij^2,
Q_i = r_i epsilon_i/4,
p_ij = a_ij/r_i,
x_ij = r_i ell_ij/2.
```

The coordinate equation gives `sum_j a_ij ell_ij=2`, and

```text
Q_i-1 = sum_j p_ij (x_ij-1)^2.
```

This variance identity is foundational. It is not the publication-program flagship.
